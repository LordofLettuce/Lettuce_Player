# Lettuce_Player 1.0
*A pleasant music player with Speech-to-Text song selection.* 
Download windows installer: [win64_install](https://github.com/LordofLettuce/Lettuce_Player/tree/main/win_installer)
## Includes:
  - http radio
  - playlists
  - song filters (Name/#/Album/Artist)
  - song/playlist search
  - relax screen
  - gif background compatibility
  - color themes
  - weather events
  - rick (yes.)
