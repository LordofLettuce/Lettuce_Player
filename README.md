# Lettuce_Player 1.0
*A pleasant music player with Speech-to-Text song selection.* 
Download installer: Lettuce_Player_Files/installer
## Includes:
  - http radio
  - playlists
  - song filters (Name/#/Album/Artist)
  - song/playlist search
  - relax screen
  - gif background compatibility
  - color themes
  - weather events
  - rick (yes.)
